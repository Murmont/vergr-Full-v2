Sign-up emails are private

Deployed

The email someone signs up with is no longer written to their public profile record. It was removed from the 15 existing records that had it, and it now stays on the login account only. Admin screens read it from there.

To show an email, a person adds it in Edit Profile → Social Links. It appears under their bio as a mail icon like any other link, and opens the mail app. DM Contact Info shows that contact email only when they've added one.

Live presence and view counts die on networks that block websockets

Your call (loosens the app's security policy)

The realtime database falls back to long-polling, which loads a script from firebaseio.com. The app's security policy doesn't allow that host, so on some office and carrier networks presence and post views stop working.

Before launch

Test content and wrong follower counts are public

Your call

Test posts on @Vergr and @Verion include a broken two-frame clip and a sound test. Follower counts on existing accounts are inflated from an old double-count, so Explore shows numbers that don't match profiles.

Before launch

The main streaming box has no backup

Your call

Box 1 runs streaming and the chat relay. The code is in the repo, but its running configuration isn't backed up anywhere. If it dies, live streaming and chat go with it until it's rebuilt by hand.
