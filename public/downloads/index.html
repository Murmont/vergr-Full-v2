Windows SmartScreen notice: this beta build is not yet code-signed with a paid certificate. Windows may show "Windows protected your PC" the first time you run the installer. Click More info → Run anyway. This is expected for sealed betas and will go away once the production cert is in place.

1 Install

  1. Double-click VERGR-Setup.exe.
  2. If SmartScreen appears, click More info → Run anyway.
  3. Accept the install path (defaults to %LOCALAPPDATA%\VERGR).
  4. Launch VERGR from the Start menu.

2 Sign in

Create a new account or sign in with Google. Google sign-in opens your default browser briefly to handle the OAuth redirect — this is normal and returns control to the app automatically.

Note for reviewers: coin purchases are intentionally disabled in this beta — payment processing is connected after the production domain + business email are live. All other features (posts, squads, chat, live streaming, quests, Watch-to-Earn) are fully functional.

3 Data & storage

  • App binary: %LOCALAPPDATA%\VERGR
  • WebView cache & auth tokens: %APPDATA%\com.vergr.desktop
  • Your posts, chats, wallet: Firebase (cloud). Nothing game-critical is stored locally.

Uninstall via Settings → Apps → VERGR → Uninstall. To wipe local cache too, also delete the %APPDATA%\com.vergr.desktop folder manually.
